# Procedimentos operacionais padrão (POPs)

> *EN summary: standard operating procedures derived from the data analysis (Phases 4–9). Each SOP
> traces back to the finding that motivated it and carries its own KPI targets.*

| POP | Processo | Achado que motivou | Meta principal |
|---|---|---|---|
| [POP-01](POP-01_recebimento_refrigerado.md) | Recebimento refrigerado | 27–63% dos paletes frios acima do tempo de doca; 17% das carretas congeladas acima de −18 °C | < 5% acima do tempo de doca |
| [POP-02](POP-02_putaway_leitura_endereco.md) | Putaway com leitura de endereço | Erro de putaway 4× no turno 2 e 6–7× no operador 3 | < 2 erros por mil paletes |
| [POP-03](POP-03_separacao_fefo.md) | Separação FEFO e conferência | FEFO violado em 19% dos SKU-dias | ≥ 99% das linhas no lote indicado |
| [POP-04](POP-04_inventario_ciclico.md) | Inventário cíclico ABC | Acuracidade 96%; itens A contados menos que os C | ≥ 98,5% por endereço |

Os POPs refletem um CD **fictício** (Sapucaí Distribution Center) e servem como modelo de formato e conteúdo.
